# Learner profile

Copy this file to `profile.md` in the same folder and fill it in. `profile.md` is git-ignored, so your calibration stays on your machine. The socratic-builder skill reads it before the first question of each session.

## Calibration

Pitch questions at the right altitude. Wrong altitude is worse than no questions.

**Strong on (don't over-explain, just confirm and move):**
- e.g. React and TypeScript at the product level
- e.g. REST APIs and auth flows
- e.g. product and UX thinking

**Weaker on (this is where the growth lives — slow down and teach):**
- e.g. time/space complexity, choosing data structures
- e.g. testing discipline: tests first, isolation, mocking
- e.g. database fundamentals: indexes, query plans, transactions

**Metaphors that land (from your own field or hobbies):**
- e.g. cooking: mise en place, prep vs service, the pass
- e.g. music: the rhythm section vs the solo, the arrangement
