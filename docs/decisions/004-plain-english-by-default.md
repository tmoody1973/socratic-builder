# 004 — Plain English by default, technical on request

**Decision** — Everything the skill says, including journal entries and the website, is in plain English by default: everyday words, with any technical term defined in one clause the first time. A "technical" setting (overall or per topic) switches to precise terms without definitions.

**Why this came up** — The skill is meant for everyone from people who never read code to senior engineers. One voice can't serve both: jargon loses beginners, and constant definitions annoy experts.

**Options**
- Technical by default, simpler on request: fits engineers, but beginners bounce off before they know to ask.
- Plain only: welcoming, but experts find it slow, and it never teaches the real vocabulary.
- Plain by default, with a technical switch, "teach me the words" in between, and per-topic overrides: covers the whole range, but the skill has more to keep track of.

**What we chose and why** — Plain by default, with the switch. Tarik raised it; Claude proposed the per-topic override. The "teach me the words" middle setting keeps real terms in play, so beginners learn the vocabulary instead of having it hidden from them.

**What we gave up** — Experts must set the dial once (or say "more technical") before the skill fits them. Plain explanations are a little longer.

**How we'll know if this was right** — A non-technical user finishes a session without asking what a word means, and an engineer who set "technical" never gets a definition they didn't need.
